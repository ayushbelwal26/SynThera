# Drug Combination Discovery

This project is an explainable Graph Neural Network (GNN) system designed to predict synergistic drug combinations. It integrates biomedical knowledge from PrimeKG with experimental synergy labels from the DrugComb database to model complex drug-target-disease interactions. Using GNNExplainer, the system generates interpretable subgraph explanations that highlight the mechanistic pathways and critical biological entities driving synergy predictions.
